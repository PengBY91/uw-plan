# W3-04 B 线仿真对照（B0 → B1 → B2a → B2c）

**结论：B0（SGBM 双目稠密体素）、`map` 和 `eval-map` 已补齐，B1/B2a/B2c 三种声呐更新已在三个有结构的仿真场景上跑完，每个场景各用真值、A0、A1（声呐关）三种位姿，共 36 张地图，全部成功；A1 后端修复后又用全程 A1 位姿重建了斜墙的 4 张地图。** 用真值位姿时，B2a 和 B2c 都提高了可见表面的覆盖：可见表面召回在壁柱墙从 0.403 升到 0.520 / 0.596，在条纹横梁从 0.358 升到 0.573 / 0.686，在斜墙从 0.559 升到 0.723 / 0.739。代价是仰角弧带来的错误占据：条纹横梁上 B2a 落在结构外的占据比例从 1.5% 升到 14.4%，斜墙从 1.9% 升到 30.0%；上下层错误占据在条纹横梁升高一个数量级以上（B0 0.0001 / 0.0003，B2a 0.0034 / 0.0056）。用真值位姿时四种方法的错误空闲率都 ≤ 0.0014。地图质量主要受位姿限制：用 A0 位姿时，壁柱墙的错误空闲率达到 0.54，声呐更新改变不了这一点。另外发现 `eval-map` 的"占据召回"实际衡量的是结构内部体素，会奖励位姿误差造成的拖影，所以本报告改用表面带指标（见第 4 节），并且没有改动共享的 `eval-map`。

这些都是仿真结果。仰角 20° 是仿真设定，不是平台孔径；声呐和双目都来自 HoloOcean 仿真，没有任何实测数据，因此不能勾掉需要 D1–D3 的清单项。

## 2 方法

- **B0**：双目深度体素化，射线经过的体素记空闲，端点记占据，带来源和更新时间。
- **B1（诊断）**：把每个回波放在仰角 0 处记占据，即水平投影假设：回波来自声呐所在的水平面。只用于对照。
- **B2a（保守）**：每个回波的整段仰角弧（±10°）都记占据；没有回波不清空，无法确认的体素保持未知。
- **B2c（Two-Stage 复现，仅 Stage 1）**：每个回波对应的三维反射区域（距离 bin × 方位 bin × 整个孔径）逐体素独立加一次命中；在每个有回波的方位列里，首回波前方（扣除一个体素的保护带）记"已验证为空"，首回波后方记"遮挡"，只计数不更新；同一帧里是候选的体素不算空；整列都没有回波时不更新。复现偏差见第 5 节。

### 观察

1. **真值位姿下，声呐增加了表面覆盖，代价是错误占据。** B2a 和 B2c 的可见表面召回都高于 B0，B2c 最高。增加的错误占据集中在结构外侧和上下层，与"整段仰角弧都记占据"的预期一致：对竖直墙，弧沿竖直方向展开，基本落在墙面里（壁柱墙结构外占据只有 2.6–3.6%）；对横梁和斜墙，弧会伸到结构外面（14% 和 30–33%）。B2a 在条纹横梁上层和下层的错误占据分别是 B0 的约 30 倍和 20 倍。这正是 B2a 设计时接受的"偏厚但安全"，这里给出了它在仿真孔径下的量级。
2. **B2c 和 B2a 的取舍。** 每个场景里 B2c 的有效覆盖都最高（多出来的是已验证为空的体素），真值位姿下错误空闲率不高于 B2a（≤ 0.0010），错误占据略高于 B2a；A0 位姿下 B2c 的错误空闲率反而高于 B2a（壁柱墙 0.563 对 0.539），因为它的空闲更新同样受位姿误差影响。没有对 B2c 做调参。
3. **B1 与 B0 几乎相同。** 只在仰角 0 处写点，新增的占据很少；斜墙上 B1 的结构外占据比 B0 高（5.5% 对 1.9%），因为斜面回波实际来自非零仰角，零仰角假设把它们放错了位置。
4. **位姿误差压过建图方法的差异。** 用 A0 位姿时，壁柱墙有 79% 的占据落在结构外，错误空闲率 0.54（双目空闲射线穿过了真实结构的位置）；声呐更新基本不改变这一点。A1 声呐关的位姿在壁柱墙上接近真值（错误空闲率 0.012），在条纹横梁上和 A0 相当（0.19），这与 A1 报告中条纹横梁风险模式误差 3.6 m 一致。
5. **错误空闲**（真占据被判为空闲）在真值位姿下四种方法都 ≤ 0.0014，所以不能用"减少错误空闲"来区分这些方法；只有位姿漂移时它才变大。

## 4 评价指标的问题：占据召回奖励拖影

`eval-map` 的参考 `truth_from_boxes` 会去掉结构边界两侧排除带内的体素，剩下的"真占据"大多是长方体内部。相机和声呐只能看到表面，内部体素被判为占据只可能来自位姿或深度误差把表面向内拖。例如壁柱墙 B0 用真值位姿的占据召回是 0.046，用 A1 位姿反而是 0.215。核对结果是：真值位姿下，深于 0.10 m 的内部占据体素占 9.1%；A1 位姿下占 33.4%。召回上升来自拖影，不是地图更好。

因此本报告不用 `eval-map` 的占据召回比较方法，改用 `scripts/b_surface_occupancy.py`：把体素中心按到长方体表面的有符号距离分成结构外侧、表面带（±0.10 m）和内部三类；"可见表面召回"是面向航线一侧的表面带中被判为占据的比例。原始 `eval-map` 的输出（含占据召回）保留在每个运行目录，`tables.md` 也照录，没有修改共享的 `eval-map` 行为。建议之后在 `eval-map` 里增加一个表面召回字段，同时保留原有字段。

## 5 B2c 复现偏差表

论文：Kim et al., *Two-Stage Probabilistic 3D Reconstruction …*, IJCAS 2026（wiki 论文页）。没有官方代码，以下每一项都是本实现的选择。

| 论文中的做法 | 本实现 | 原因 / 缺口 |
| --- | --- | --- |
| Stage 1：完整三维反射区域候选体素搜索，分层分治加速 | 球壳段按 ≤ 半个体素的间距稠密采样，取唯一体素；不做分层加速 | 论文没有给出算法细节和耗时；离线仿真不要求实时 |
| 考虑体素相互依赖和可达性的传感器模型，三态为占据、已验证为空、遮挡 | 每个方位列内：首回波前方记空闲（miss），扣一个体素的保护带；首回波后方记遮挡，只计数，不改 log-odds；同一帧里是候选的体素不记空；整列无回波不更新 | 论文页只描述了三态的含义，没有给出概率形式；这里取最直接的可达性规则 |
| log-odds 增量和判定阈值 | 命中 +0.85、未命中 −0.4，截断 [−2, 3.5]，阈值 0（OctoMap 默认 0.7/0.4） | **缺口**：论文没有给出这些数值，按标注的合理默认值处理 |
| 回波检测 | 图像强度 > 0.25 的固定阈值 | **缺口**：论文没有给出 |
| 俯仰视场 | 20°（仿真设定）；论文仿真为 ±7° | 用本项目仿真的孔径；平台孔径待实测 |
| 距离自适应：目标在光学量程外时只用声呐 | 声呐和双目全程同时更新 | 本轮对照的目的是单独看声呐更新规则的差异，双目部分与 B0 保持一致 |
| Stage 2：沿光学射线和声呐像素求交的约束匹配，光学深度不确定度 σ_d = 0.3 m | **没有复现**。光学按 B0 的同一套双目积分（射线空闲、端点占据） | 保持光学部分与 B0 相同，便于隔离声呐的贡献；Stage 2 留作后续 |
| 评价：体素 precision / recall / F1 / F2 | 本项目的 `eval-map` 比例加表面带指标 | 本项目协议；数值不能与论文表格直接比较 |
| 体素分辨率 | 0.10 m | 论文页没有给出 |

## 6 局限

- 每个配置只跑一次，没有重复统计；阈值都没有调。
- Dam 没有道具，无法生成长方体参考，所以没有跑；Tank 和 Pier 的原始声呐看不到道具，也没有用。要覆盖 Dam，需要从世界网格生成参考占据。
- B2c 只复现了 Stage 1，Stage 2 没有实现，所以不能宣称复现了论文的融合结果。
- 声呐取 1/5 帧、深度取 1/10 帧，是计算上的折中。
- 斜墙 A1 位姿用的是后端修复后的 `_r03`，那次运行需要 55 次 iSAM2 重建（A1 报告第 3.1 节）；修复前只覆盖 47% 的地图保留为 `_r01`。
- 表面带指标里的"可见面"按道具中心面靠近航线的一侧近似，没有做真实的可见性光线投射。
- 20° 孔径只是仿真设定；平台孔径实测之后，覆盖和错误占据的权衡需要重新计算（见 `reports/w4/b_effect_size.md`）。
