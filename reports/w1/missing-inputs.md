# W1 数据 SDK 与配置缺口清单

配合 [[plans/acoustic-optic-w1-environment-audit-2026-10|WSL 环境与仓库实测记录]]和 [[plans/acoustic-optic-month1-execution-checklist-2026-10|首月执行清单]]使用。双目已集成、水池已建是团队确认的现有条件；下列“待核验”表示本次尚未取得对应文件或证据，不等于团队没有做过相关工作。

查验范围为 WSL 已知水下工程、`underwater_ood_scheduling/{data,datasets}`、ROS 工作区及本次建立的 `~/uw-ao-lab`。没有扫描所有 Windows 磁盘、团队服务器或供应商交付盘。P0 表示阻塞当前对应链路，P1 表示后续任务依赖；公共 A0 和实机链路可分别推进。

EuRoC 使用 [ETH 官方入口](https://projects.asl.ethz.ch/datasets/euroc-mav/)及其 [Research Collection](https://doi.org/10.3929/ethz-b-000690084)。V1_01 已下载到 `~/uw-ao-lab/data/public/euroc/`，原始大文件不进入知识库或代码 Git。正式登记为 `manifests/euroc_v101.yaml`；原 pending 模板只保留准备阶段历史，不能用于判断当前状态。

现有候选位置保存在 `manifests/existing-data-registry.json`；MH_01 实际消息证据见 `reports/w1/existing-mh01-bag-info.txt`。旧数据命名、其他机器上的实验记录和公开论文传感器配置都不能替代本机验证。

## SDK 与驱动

| 优先级与状态 | 需要提供或核验 | 已有证据 | 最小验收 |
| --- | --- | --- | --- |
| P0，厂家包未定位 | 采购声呐的厂家、准确型号、序列号、固件、SDK 版本与发布包；Linux 支持的发行版、架构、编译器及依赖 | 附件称有 Linux/Windows C++、Python SDK，输出灰度图；本机存在 Oculus 驱动源码，但不能确认同设备兼容 | 厂家最小例程取得连续帧、帧号、采样时间与配置元数据；原始字节或原始灰度图可存盘并离线读回 |
| P0 对声呐定量，待核验 | SDK 图像格式说明、投影模式、像素到斜距/方位映射、垂直波束范围、无效区域、声速与增益参数 | 当前附件不足以确定投影几何；不能按 M750d 参数代入 | 用已知距离和方位目标验证正反映射，并保存实际频率、量程、增益、帧率 |
| P0，接口待核验 | 已集成双目的型号、SDK/驱动、两路原始图像、camera_info、同步模式与曝光控制 | 团队确认双目已集成；此次没有设备采集验收 | 连续读取两路图像及帧号/采样时间，核对左右同步和分辨率；若用 UVC，先证明无需额外 SDK |
| P0，接口待核验 | IMU 原始加速度/角速度、量纲、轴向、频率、时钟及传输方式 | 既有 ROS/飞控工程不能证明提供满足 VIO 的原始数据 | 静止与转动记录通过单位、轴向、时间单调和有效率检查；只提供姿态角时不能当原始 IMU 接入 OpenVINS |
| P1，待核验 | 压力深度、云台相机接口及云台角度元数据 | 平台具备相应传感器不等于统一时间接口已建立 | 深度零点、单位和时间有记录；云台动相机需角度/时变外参，不能当固定相机直接融合 |
| P0 对实机，未测 | WSL 或原生采集机网络、IP/端口、USB 映射和录制路径 | WSL 未见常用视频/串口设备节点；以太网设备未做连接验证 | 确认厂家支持的采集环境，先存原始数据再离线导入；不以 WSL 算法可编译代替采集链路验收 |

厂家 SDK 应保存在有相应访问权限的交付目录，登记版本、许可证和路径；本清单不要求把受限 SDK 上传公开仓库，也不要求取得附件已明确不提供的原始相位/幅值。

## 标定与运行配置

| 优先级 | 配置缺口 | 必需字段或文件 | 完成判据 |
| --- | --- | --- | --- |
| P0 | 水下双目标定文件尚未核验 | 实际分辨率与镜头模型、左右内参/畸变、基线和左右外参、整流参数、舱窗与标定介质、采集日期 | 留出图像极线误差、已知距离深度偏差；不能使用 EuRoC 或空气内参替代 |
| P0 | 多传感器外参与 frame 约定 | 机体、左右相机、IMU、声呐变换；矩阵方向、单位、轴向、安装版本 | 人为正向平移/转动与变换输出一致；旋转正交和变换闭环检查通过 |
| P0 | 时间模型 | 各设备时钟域、采样/接收时间、单位、偏移、抖动、重启/回跳行为 | 同事件或同步记录给出量化误差；仅配置 approximate sync 不算完成 |
| P0 | OpenVINS 本机参数 | camera/IMU YAML、噪声、话题映射、初始化条件、双目模式与时间开关 | 实际订阅原始量且模型匹配；没有参数来源时不能复制官方示例填空 |
| P0 对联机 | ROS 数据契约与设备网络配置 | 图像编码、IMU 单位、message schema、QoS、DDS 域、TF、IP/端口、驱动启动方式 | 首中尾消息可读，无错误时间戳或静默字段丢失；SDK 示例到 ROS 包装分步验收 |
| P1 | SonarSweep 独立环境配置 | 可兼容的 Python/Torch/CUDA 组合、单一 OpenCV wheel、权重、数据路径 | 官方 loader 和小样本推理通过；现有 Python 3.12 eval 环境不直接装原 requirements |
| P1 | WSL 直连网络配置 | DNS、代理/路由与 HTTPS 可用性 | GitHub、PyPI、Ubuntu 三源均可访问；目前已有 Windows 下载再离线导入的可用途径 |

待核验字段已写入 `configs/platform.pending.yaml`。它是输入核对模板，`status: pending_verification`，不是有效算法配置；真实参数验证后另存正式配置，保留原始文件和来源。
